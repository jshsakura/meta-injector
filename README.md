# 🎮 Meta-Injector

**한국어 | [English](README.en.md)**

여러 Wii 게임을 한 번에 Wii U 버추얼 콘솔(VC)로 변환해주는 도구입니다. 배치 처리와 메타데이터 자동 다운로드를 지원합니다.

## ✨ 주요 특징

### 핵심 기능
- ✅ **안정적인 설치**: 올바른 TIK/TMD 처리로 '손상된 소프트웨어' 오류 방지
- ✅ **중복 설치 지원**: 랜덤 ID 생성으로 동일 게임의 다른 버전도 설치 가능
- ✅ **메타데이터 추출**: ISO/WBFS 파일에서 직접 게임 코드를 읽어 정보 확인
- ✅ **안전한 작업**: 임시 폴더에서 작업하여 원본 파일 보호
- ✅ **다양한 포맷**: WBFS, ISO, NKIT, Decrypted ISO (.iso.dec), NGC (.gcm) 지원
- ✅ **강력한 패치 시스템**:
  - 200여 개 게임에 대한 클래식 컨트롤러(CC) 패치 내장
  - 호환성 DB를 통한 게임패드 지원 자동 감지
  - 슈퍼 마리오 갤럭시 1/2 게임패드 완벽 지원 (AllStars/Nvidia 프로필)
  - 사용자 정의 GCT 패치 지원

### 배치(Batch) 작업
- 🚀 **대량 변환**: 수십 개의 게임을 목록에 추가해 한 번에 처리
- 📊 **상태 모니터링**: 대기열의 각 게임별 진행 상황 실시간 확인
- 🎨 **이미지 자동화**: GameTDB에서 고품질 아이콘과 배너 자동 다운로드
- 🌍 **언어 지원**: 한국어/영어 UI 제공
- 🎮 **다양한 컨트롤러**: 게임패드, 클래식 컨트롤러 등 7가지 프로필 지원

### 이미지 & 데이터 관리
- 🖼️ **이미지 캐싱**:
  - 아이콘과 배너를 자동 저장하여 다음 작업 시 속도 향상
  - 직접 설정한 이미지는 재생성 시에도 유지됨
- 🌐 **GameTDB 연동**:
  - 게임 제목과 표지 이미지를 자동으로 가져옴
  - 편집 창에서 언제든 최신 이미지로 업데이트 가능
- 🔍 **호환성 데이터베이스**:
  - 게임별 최적의 컨트롤러 설정 자동 추천
  - GCT 패치 필요 여부 자동 표시
- ✏️ **편리한 편집**:
  - GUI에서 바로 게임 제목과 이미지 수정
  - ISO 트림 방지 옵션 (일부 세이브 충돌 게임용)
  - WBFS 파일 포맷 자동 감지 및 안내

## 📋 시스템 요구사항

- **Python 3.8+** (소스 코드 실행 시)
- **Wii U Common Key** (필수)
- **베이스 타이틀 키** (최소 1개 필수)
  - Rhythm Heaven Fever (USA)
  - 또는 Xenoblade Chronicles (USA), Super Mario Galaxy 2 (EUR)

[Releases 페이지](https://github.com/jshsakura/meta-injector/releases)에서 최신 `Meta-Injector.exe`를 다운로드하여 실행하세요.

1. 저장소 클론:
   ```bash
   git clone https://github.com/jshsakura/meta-injector.git

   ```
2. 패키지 설치:
   ```bash
   pip install -r requirements.txt
   ```
3. 실행:
   ```bash
   python run.py
   ```

## 🎮 사용 방법

### 1. 실행 및 설정

1. `Meta-Injector.exe` 실행 (또는 `python run.py`)
2. **⚙ 설정** 버튼 클릭
3. **Wii U Common Key**와 **베이스 타이틀 키(Rhythm Heaven Fever)** 입력 (초록색 불이 들어와야 함)
4. 출력 폴더 설정 (선택 사항)
5. **저장** 클릭

### 2. 게임 변환하기

#### 기본 사용법
1. **파일 추가** 버튼을 눌러 Wii 게임 파일(.wbfs, .iso 등)을 선택합니다.
2. 자동으로 게임 정보를 읽어오고 이미지를 다운로드합니다.
3. 목록에서 게임을 확인하고 필요하면 **편집** 버튼을 누릅니다.
   - 제목이나 이미지를 수정할 수 있습니다.
   - **ISO 트림 비활성화**: 슈퍼 페이퍼 마리오 등 원본 용량이 필요한 게임에 체크
4. **패드 옵션**에서 원하는 컨트롤러 방식을 선택합니다. (CC 패치가 있으면 자동 추천됨)
5. **빌드 시작** 버튼을 누르면 변환이 시작됩니다.

#### 대량 변환 (배치 작업)
1. 여러 게임 파일을 한 번에 선택하여 목록에 추가합니다.
2. 모든 게임의 정보와 이미지가 자동으로 준비됩니다.
3. 목록을 훑어보며 설정을 확인한 뒤 **빌드 시작**을 누르면 순차적으로 모두 변환됩니다.

## 🎮 GCT 패치 및 컨트롤러 시스템

이 도구의 가장 강력한 기능은 **다양한 컨트롤러 패치(GCT) 시스템**입니다.

### 1. 자동 CC(클래식 컨트롤러) 패치
- **일부 지원되는 게임**을 **Wii U 게임패드**로 플레이할 수 있도록 클래식 컨트롤러 패치를 제공합니다.
- 게임을 목록에 추가하면 패치 가능 여부를 확인하여 알림을 띄우고 설정을 제안합니다.

### 2. 사용자 지정 GCT
- 사용자가 직접 만든 치트 코드나 패치(.gct)를 적용할 수 있습니다.
- `games` 폴더 등에 같은 ID의 `.gct` 파일이 있으면 자동으로 인식합니다.

### 3. 특수 게임 패치
- **슈퍼 마리오 갤럭시 1 & 2**: 위모트 포인팅 기능을 오른쪽 아날로그 스틱으로 대체하는 전용 패치(AllStars / Nvidia 방식)를 완벽 지원합니다.

### 🛠 지원하는 컨트롤러 모드
| 모드 | 설명 |
|------|------|
| **No Pad (Wiimote)** | 순정 상태 (위모트 사용) |
| **Pad CC** | 클래식 컨트롤러 에뮬레이션 (게임패드 사용) |
| **Pad Wiimote(↕/↔)** | 위모트를 세로/가로로 잡는 설정 강제 |
| **Galaxy Patch** | 갤럭시 시리즈 전용 최적화 패치 |

## ⚠️ 참고 사항

- **손상된 소프트웨어 오류**: Wii U에서 실행 시 이 오류가 뜬다면 암호화 키가 정확한지, 베이스 파일이 잘 다운로드되었는지 확인하세요.
- **이미지 다운로드 실패**: 인터넷 연결을 확인하거나, GameTDB 서버가 일시적 장애일 수 있습니다. 수동으로 이미지를 지정할 수도 있습니다.
- **nfs2iso2nfs 오류**: ISO 파일 경로에 특수문자가 있거나, 파일이 손상되었을 수 있습니다.
